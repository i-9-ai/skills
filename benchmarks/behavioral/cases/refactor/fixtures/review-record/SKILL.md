# Skill Review Record

Prepare one review-evidence note for a supplied skill identity, review request
and evidence references. This procedure organizes facts; it does not judge
quality or authorize publication, installation or changes to the skill.

Record package identity, the review question, artifacts actually inspected,
missing evidence and next reviewer handoff. Do not fill absent results from
memory or infer completion from a file being present.

When an artifact is missing or the skill name refers to more than one source,
read `references/recovery.md`. Preserve the source distinction and report the
gap. Resolve the resource relative to this package and write to the caller's
selected workspace. No provider, global directory or helper is required.
