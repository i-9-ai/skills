# Icon source

The primary metaphor is an optional registration toggle, with a small local
receipt beneath it. Existing sibling source receipts contained no toggle_on or
toggle_off glyph. The teal frame, toggle silhouette and ledger mark distinguish
this package from collection analytics, discovery and installation icons.

The geometry is adapted from
[Material Icons toggle_on](https://github.com/google/material-design-icons/blob/40a7a292a79d9394157e1ea24f83d52d5e17c556/src/toggle/toggle_on/materialicons/24px.svg).
The immutable source SHA-256 is
`5b2cea3a0c4439affcdcfe34e6ed89722c09c174d0a4e5af790e73a38fa388bf`.
The upstream root LICENSE grants Apache-2.0; no root NOTICE was present in the
reviewed tree. The full license and attribution are bundled in LICENSE and NOTICE.
The source path is unchanged; original modifications add framing, color,
ledger strokes and the receipt-status dot.

The 100-pixel PNG was rendered from the reviewed SVG with rsvg-convert 2.63.2
and Cairo 1.18.6. Paired source/artifact hashes and dimensions are recorded in
`icon.render.json`. Visual inspection found a clear silhouette and contrasting
foreground without dependence on color alone. The SVG contains only inactive
local geometry and an accessible title. This is a local asset review, not
provider UI execution or a trademark claim.
