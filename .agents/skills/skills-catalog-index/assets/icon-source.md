## Reuse and modifications

Reuse decision: adapt the 24-pixel storage glyph to represent a local aggregate index. The visible path matches the pinned source after normalizing SVG command separators; the surrounding SVG document is modified. The local design adds a 64-pixel gradient frame, backing circle, accessible title, white glyph color and translation/scale. `icon.png` is the bundled large rendering of the local SVG.
