# Package provenance

## Naming decision

The selected name is `skill-domain-research`: the domain is skill work, and the responsibility is researching one proposed skill's subject. Singular `skill` reflects one target responsibility and one dossier. The repository catalog and active global inventory contained no exact collision on the observation date. Public searches found similar names such as `domain-research` used for internet-domain selection and `domain-research-team` used for broad research orchestration; those meanings would create routing ambiguity, so the domain-first qualifier was retained. The collision check is scoped, not a claim of global uniqueness.

## Verification contract

The package should be checked for one responsibility, three-track separation, mandatory opened web authority, source/revision/date fields, conflict and unknown preservation, private-query sanitization, normative applicability gates, and explicit separation between research findings and a qualified human's case-specific determination or advice. Structural validation and repository tests establish only their exercised invariants; behavioral evaluation must use synthetic process, candidate-skill, and public-authority inputs.
