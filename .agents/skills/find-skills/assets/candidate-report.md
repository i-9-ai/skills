## Per-source evidence

Record the full relevant inventory, file hashes, inspected/uninspected resources, specific useful contributions, dependencies, side effects, portability, maintenance, tests actually observed, license notices, and concrete risks. Mark unknown results as unknown.

## Recommendation

Choose reuse unchanged, selective adaptation, reference, or original authoring. Explain why the candidate fits the single responsibility, what is not reused, and what the next specialist needs. Return a search gap when no suitable base exists.
