# Visual sources and originality

Use symbol libraries as a searchable vocabulary and preferred source of recognizable metaphors. Before copying or adapting geometry, pin the source revision, record the icon name and license, and preserve required notices. Do not redraw a common symbol from scratch when a compatible library already supplies a clear version.

| Source | Useful role | License note |
| --- | --- | --- |
| [Lucide](https://lucide.dev/icons/) | Broad outline-symbol vocabulary with consistent optical rules | ISC; brand logos are intentionally excluded |
| [Heroicons](https://heroicons.com/) | Clear small-size outline and solid primitives | MIT |
| [Material Symbols](https://fonts.google.com/icons) | Extensive action and object vocabulary with adjustable weight and fill | Apache-2.0 |
| [Phosphor Icons](https://phosphoricons.com/) | Expressive families with several weights | MIT; verify the selected release |
| [Tabler Icons](https://tabler.io/icons) | Technical and interface symbols with broad coverage | MIT; verify the selected release |
| [Iconify](https://icon-sets.iconify.design/) | Search index across many icon sets | Each collection has its own license; Iconify is not a blanket reuse license |
| [Simple Icons](https://simpleicons.org/) | Provider and product marks for provider-specific skills | Review the source license and the trademark owner's usage rules separately |

Prefer this sequence:

1. derive a metaphor from the skill's action and primary output;
2. find a named established symbol with a compatible license and a clear small-size silhouette;
3. preserve its recognizable meaning and record source, revision, icon name, and license in the asset or package documentation;
4. add collection identity through palette, framing, depth, or restrained composition without obscuring the symbol;
5. compare the full sibling set at small size and revise collisions.

Generative image tools may propose directions or produce a raster derivative when authorized. Do not upload private package content, hidden prompts, client data, or proprietary artwork. Record the provider and rights relevant to the generated output. A generated image still requires visual review, small-size legibility, uniqueness, and active-content checks.
