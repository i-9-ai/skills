# Synthetic intake example

Goal: prepare a focused issue-drafting skill from complementary reproduction and privacy procedures.

Primary output: one local Markdown issue draft. Publishing, assigning people, release work, and production access are outside scope. The skill must preserve supplied observations, state missing evidence, and remove sensitive diagnostic values without inventing replacements.

Acceptance criteria: one responsibility; positive and negative triggers; explicit source decisions; a package LICENSE; no provider prerequisite; no external side effect; a scoped behavioral evaluation. The default correction budget is two rounds.

This fixture is a draft demonstrating how to record a verified intake artifact. Later stages are intentionally absent until their outputs actually exist. It is not a completed evaluation or production evidence.
