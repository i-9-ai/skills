# Evidence packet icon

The stacked-document metaphor represents collected evidence without suggesting
a passing evaluation. This replaces the prior checklist/checkmark, which
overlapped the evaluator responsibility.

Geometry: [Lucide files](https://github.com/lucide-icons/lucide/blob/f12b0de177fbc2a6795e99be065887e72b237123/icons/files.svg),
reviewed 2026-09-19. The ISC notice is retained in the package NOTICE. The
original square frame and palette remain Apache-2.0. The SVG uses no external
resources. icon.png is the 128 by 128 rendering produced with librsvg.
